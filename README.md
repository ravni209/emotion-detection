# Emotion Detection Application

## Project Name
Emotion Detection using IBM Watson NLP

## Description
This project is an emotion detection application that uses the IBM Watson NLP Emotion Prediction API to analyze text and identify the emotions expressed in it.

## Emotions Detected
- Anger
- Disgust
- Fear
- Joy
- Sadness

The application also identifies the dominant emotion based on the highest emotion score.

## Main File
`emotion_detection.py`

This file contains the `emotion_detector()` function, which sends the input text to the Watson NLP Emotion Prediction API and returns the detected emotion scores.

## Technologies Used
- Python
- IBM Watson NLP
- Requests library

## Project Purpose
This project was created as part of the IBM/Coursera Python and Flask final project to demonstrate the use of an external AI/NLP service for emotion detection.
